# НейроАссистент

Исследовательский прототип локальной экранной клавиатуры для конкурсной работы «Система». Классификатор CSP + LDA использует три ЭЭГ-канала C3, Cz, C4. Команды: левая рука, правая рука, обе ноги и покой. В текущем прототипе команды управляют клавиатурой внутри веб-приложения. Управление всей ОС и подключение конкретной гарнитуры ещё не проверены.

## Измеренный результат на реальных открытых записях

Офлайн-пилот PhysioNet EEGMMIDB v1.0.0: пять последовательных участников S001–S005, без отбора по точности. Для каждого своя модель. Обучение R04/R06/R08/R10, проверка R12/R14. Это разные прогоны одного участника, не разные люди и не разные дни. Из 30 EDF-файлов получены 526 обучающих и 263 проверочных эпохи. Один фрагмент 1,5 с на событие, от +1 до +2,5 с после метки. Тестовые записи не использованы для подбора параметров.

Среднее по участникам: accuracy **55,5%**, balanced accuracy **35,4%**, macro-F1 **0,351**. Простое постоянное предсказание «покой» даёт **57,0% accuracy** и **25% balanced accuracy**. Преимущества по общей точности нет. Модель пока не готова к надёжному самостоятельному управлению.

| Участник | Train | Test | Accuracy | Balanced accuracy | Macro-F1 |
|---|---:|---:|---:|---:|---:|
| S001 | 106 | 53 | 54.7% | 41.5% | 0.416 |
| S002 | 104 | 52 | 57.7% | 40.5% | 0.384 |
| S003 | 106 | 53 | 52.8% | 32.9% | 0.341 |
| S004 | 105 | 53 | 62.3% | 37.6% | 0.382 |
| S005 | 105 | 52 | 50.0% | 24.4% | 0.234 |

Ноги записаны в другом типе задания, чем отдельные руки. Этот контекст может влиять на результат. Пилот мал, данные не подтверждают эффективность для людей с двигательными нарушениями. Результаты имитатора (около 93% для трёх команд, 78% с покоем) сохранены отдельно в `experiments/results/` и не являются точностью на человеке.

## Запуск

Python 3.12. Из корня репозитория:

```powershell
python -m pip install -r requirements.txt
python run_demo.py
```

Синтетический режим: http://127.0.0.1:8765. Кнопка «Демо» задаёт имитатору целевую фразу. Это автоматизированный сценарий, не результат набора человеком.

```powershell
python run_replay.py
```

Реальные данные: http://127.0.0.1:8766. Кнопка «Воспроизвести 53 эпохи» по очереди подаёт отложенные обработанные фрагменты S001 в сохранённую модель. Предсказания поступают в ту же экранную клавиатуру. Интерфейс показывает истинную метку, прогноз и число совпадений. Целевая фраза не задаётся, осмысленный текст и скорость ввода не оцениваются. Это дискретное офлайн-воспроизведение, не непрерывное управление по живой ЭЭГ. По завершении оно останавливается.

## Повторить обучение

```powershell
python scripts/download_physionet.py
python scripts/train_physionet.py
python -m unittest discover -s tests -v
```

Загрузка: около 77 МБ. Манифест содержит URL, размер и SHA-256 каждого исходного EDF. Скрипт проверяет размер по заголовку EDF и дозагружает оборванные файлы. Изменение опубликованных данных или версий библиотек может изменить результат.

Модель не является нейросетью. В каждом из диапазонов 8–13 и 13–30 Гц CSP учится только на обучающих эпохах выделять пространственные фильтры «один против остальных», затем логарифмы относительных дисперсий поступают в LDA (lsqr, shrinkage=auto). Получается 16 признаков. Параметры зафиксированы до оценки теста. Для нового человека необходима собственная калибровка и отдельная проверка. Автоматического самообучения в коде нет.

## Файлы модели и проверяемость

- `models/S001.json` ... `S005.json`: числовые параметры CSP и LDA, каналы, частота и разбиение. Без pickle и исполняемых вложений.
- `neuroassist/portable.py`: загрузка параметров и инференс.
- `results/physionet_results.json`: метрики, матрицы ошибок, истинные и предсказанные классы, версии ПО.
- `results/data_manifest.json`: источники и SHA-256 исходных файлов.
- `results/replay_S001.npz`: 53 обработанные отложенные эпохи, метки и прогнозы для офлайн-показа.
- `results/replay_events.json`: соответствующие события и номера прогонов.

Внутри демо индикатор качества сигнала вычисляется по амплитуде и сетевой помехе. Он не измеряет импеданс электродов. В режиме записи контакт с человеком не измеряется. Модуль BrainFlow — заготовка адаптера, совместимость с NeuroPlay/Neiry не установлена. NeuroPlay-8Cap регистрирует 125 Гц, PhysioNet — 160 Гц, имитатор — 250 Гц. Модель и фильтры нужно настраивать под частоту и монтаж устройства.
